## 这是什么

自媒体/内容运营「发布前合规 + 起量双检」工具。把标题和正文粘进来，一次搞定：
1. **多平台违禁词检测**——小红书 / 抖音 / 公众号 / 视频号 多词库，按平台分别判定
2. **变体词识别**——谐音（v信）、拼音（zhuan米）、emoji 分隔（减✨肥✨药）、缩写（s码）等平台已能识别的变体
3. **命中解释 + 改写建议**——每个命中词给出「为什么违规 + 敏感平台 + 替换建议」，可一键替换
4. **AI 生成内容标注自查**——对照《人工智能生成合成内容标识办法》（2026-06-14 落地）
5. **发布前起量自检清单**——标题搜索词 / 首图 / 互动钩子 / 话题 / 发布时间窗口
6. **本地离线**——检测全部在本机完成，无次数限制
7. **行业筛选**——通用 / 医疗 / 财经 / 美妆 / 教育 / 电商，按行业查词，减少误报
8. **自定义词库**——把你行业里容易被误判的词加进来（只存本机浏览器，不上传）
9. **批量检测**——多篇文案用 `---` 分隔，逐篇出结果
10. **AI 改写指令导出**——一键复制改写 prompt，粘贴到你的 AI 工具即可获得合规改写稿
11. **报告下载**——检测结果一键导出 .md 文件

## 使用

直接双击打开 `index.html`（纯浏览器，零依赖，无需安装，断网可用）。

词库扩充：加载 `dict/words.json`（文件选择器）即可覆盖/扩充词库，便于随平台规则更新。

## 词库分级（防误判设计）

| 级别 | 含义 | 处理 |
|---|---|---|
| 确定违规 | 平台明文 / 广告法明令 | 红标，强烈建议修改 |
| 疑似违规 | 需结合上下文自查 | 橙标，人工判断 |
| 场景相关 | 同一词在不同平台判定不同（如「直播间」抖音✅ / 小红书⚠️） | 蓝标，仅敏感平台显示 |

## FAQ / 避坑指南（TRACE 规范性，防 lmd 4.4 扣分点）

**Q1：查出来的词一定违规吗？** 不一定。「确定违规」是广告法/平台明文，基本要改；「疑似/场景相关」需结合上下文人工判断，不构成合规承诺。
**Q2：词库多久更新？** 随每日情报更新（社区整理稿，标注来源）；首版 76 词覆盖高频词，漏词正常——把你行业的词加进「自定义词库」。
**Q3：文案会传出去吗？** 不会。检测 100% 在本机完成，无任何网络请求；自定义词只存本机浏览器 localStorage。
**Q4：为什么"直播间"小红书显示、抖音不显示？** 平台语境判定——同一词不同平台规则不同，这是与"一刀切"查词站的差异点。
**Q5：批量怎么用？** 多篇用 `---` 分隔，自动逐篇出结果。
**Q6：变体写法能躲过平台吗？** 不能。平台 AI 已识别 v信/减✨肥✨药/zhuan米，别用变体规避，直接改合规表达。
**Q7：报告怎么存？** 「下载报告 .md」保存本地，或「生成报告」后手动复制。

## 常见问题（FAQ）

**装完第一步先干什么？**
直接跑一次自带的示例，看到输出长什么样再换成自己的数据，别一上来就改配置。

**我的数据会不会被上传？**
不会。全程在你自己的电脑上跑，不联网、不上传，关掉就没了。

**跑不起来最常见的原因？**
九成是运行环境版本不对。先确认版本，再看报错第一行——第一行基本就写明了缺什么。

**词库能自己加词吗？**
能，词库是纯文本，加一行就是一条。

**会不会误判？**
会有，它只做提示不做删改，最终判断留给你。

**支持哪些平台的规则？**
通用词族为主，平台差异靠你自己往词库里补，补完就变成你自己的规则。
